## Platforms

The same code runs on the JVM and under Scala.js. The published core needs no native library and
no JVM flags.

On the JVM you can also import an optional backend, the Vector API or BLAS and LAPACK, to speed
up the operations it supports. Results keep the same types and meaning, though the last few bits
may differ, because a backend can add numbers in a different order.
[The numerical contract](advanced/numerical-contract/) says exactly what is guaranteed.

## Install

<Aside type="note" title="First milestone">
	`0.1.0-M1` is on Maven Central for the JVM and Scala.js. It is a milestone, not a 1.0
	compatibility promise. The Breeze interop module and the JVM backends are not yet published.
	Pages marked as development previews describe APIs that are not in a release.
</Aside>

Gale is built with Scala 3.7.4 and needs JDK 21 on the JVM. Add the core to `build.sbt`:

```scala
scalaVersion := "3.7.4"
libraryDependencies += "io.github.canardlapin" %% "gale-core" % "0.1.0-M1"
```

For Scala.js or a cross-project, use `%%%` instead of `%%`.
[Modules and platforms](reference/modules-and-platforms/) lists every module and what it needs.
