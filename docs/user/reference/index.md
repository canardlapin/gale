# Reference

Reference pages summarize stable public capabilities. Use Scaladoc for exact
types, signatures, and symbol-level contracts.

- [Factorization capabilities](factorization-capabilities.md) explains the
  common solve interfaces implemented by LU, Cholesky, and QR factors.
- [Numerical, sparse, and backend contract](../advanced/numerical-contract.md)
  records ordering, tolerance, failure, portability, and backend guarantees.

Gale is still preparing its first public release. The
[Getting started](../getting-started.md) page therefore distinguishes planned
coordinates from artifacts that are actually available.
