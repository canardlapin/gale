# Reference

Reference pages summarize stable public capabilities. Use Scaladoc for exact
types, signatures, and symbol-level contracts.

- [Factorization capabilities](factorization-capabilities.md) explains the
  common solve interfaces implemented by LU, Cholesky, and QR factors.
- [Modules and platforms](modules-and-platforms.md) maps live build projects to
  their runtime and publication boundaries.
- [Numerical, sparse, and backend contract](../advanced/numerical-contract.md)
  records ordering, tolerance, failure, portability, and backend guarantees.
- [Troubleshooting](../troubleshooting.md) starts from typed failures, runtime
  requirements, and allocation-resource mistakes.

Gale `0.1.0-M1` is available from Maven Central.
[Getting started](../getting-started.md) shows the released core dependency;
[Modules and platforms](modules-and-platforms.md) distinguishes published
artifacts from provisional integrations.
